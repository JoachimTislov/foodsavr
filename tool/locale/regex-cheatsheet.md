
| Symbol | Meaning                                              | Think of it as                     |      |
| ------ | ---------------------------------------------------- | ---------------------------------- | ---- |
| `[]`   | Character class                                      | "One of these characters"          |      |
| `[^]`  | Negated character class                              | "Anything except these characters" |      |
| `()`   | Capturing group                                      | "Remember this part"               |      |
| `(?:)` | Non-capturing group                                  | "Group only; don't remember"       |      |
| `.`    | Any character (except newline in many regex flavors) | "Wildcard"                         |      |
| `\.`   | Literal dot                                          | "An actual `.`"                    |      |
| `+`    | One or more                                          | "Repeat at least once"             |      |
| `*`    | Zero or more                                         | "Repeat any number of times"       |      |
| `?`    | Zero or one                                          | "Optional"                         |      |
| `\s`   | Whitespace                                           | "Space, tab, newline, etc."        |      |
| `\b`   | Word boundary                                        | "Start/end of a word"              |      |
| `      | `                                                    | Alternation                        | "OR" |
| `\(`   | Literal `(`                                          | "An actual opening parenthesis"    |      |
