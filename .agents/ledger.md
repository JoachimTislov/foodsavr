# Repository ledger

This file stores historical repository events. Keep active instructions in
`AGENTS.md`; read this ledger only when historical context is needed.

Add new entries at the top of the table using UTC dates. Record what changed,
what was committed, pushed, or replied to, and any unresolved blocker.

For session-linked work, also register the provider session in
`.agents/sessions/index.jsonl`. Include the real session ID, provider, harness,
issue references, pull requests, external sources, commit SHAs, and outcome in
both records. Session IDs are correlation identifiers; transcripts and
credentials remain outside the repository.

Use `scripts/agents/agentctl knowledge rebuild` to materialize the ledger,
specifications, and documentation into the ignored SQLite query projection.
The Markdown ledger remains the append-only historical record; the session
JSONL is a compact upserted snapshot with attempt history, and SQLite is the
derived relational and full-text index.
