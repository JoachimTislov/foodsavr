---
name: compress-memory
description: Compress a document or context while keeping what it must still convey.
disable-model-invocation: true
metadata:
  audience: human
---

1. Ask which details must survive and where to focus, unless the user already said.
2. Identify the core information or behaviour the content must retain.
3. Remove redundancy and exposition that does not serve that core; prefer leading words over restatement (see `writing-for-agents`).
4. Check the result still conveys every retained point, and report what was dropped.
